# Продукт

PoDolyam для Windows помогает одному организатору разделить оплаченный им ресторанный счёт и учесть возвраты. Участникам аккаунт не требуется. Текущая версия работает локально в отдельном окне; доступ определяется учётной записью Windows.

## Сценарий

Группа и описание встречи → участники и плательщик → позиции чека и назначения → таблица итогов, лог подсчёта и статистика → фиксация → персональные сообщения и возвраты.

Название, описание до 1000 символов, дата, заведение, валюта RUB. Количество положительное целое; стоимость строки определяется количеством и ценой единицы в копейках. Распределение одному, поровну выбранным, на всех текущих участников, по единицам или весам. Нераспределённые позиции видимы и блокируют фиксацию.

Снимок нельзя редактировать. Долг плательщика самому себе отсутствует. Частичные получения уменьшают остаток; переплата отклоняется. Ошибочный перевод отменяется с причиной, запись сохраняется. Закрытие — после полного возврата.

## Передача расчёта

Кнопка копирует текст; организатор отправляет его сам. Персональный PDF сохраняется через диалог Windows и содержит только выбранного участника. Это копия, не обновляемая после платежей; уже отправленный файл невозможно отозвать. Публичных ссылок без серверной части нет.

## Ограничения прототипа

Нет установщика, цифровой подписи, синхронизации, шифрования базы приложением и автоматического бэкапа. Исправление зафиксированного чека сейчас требует вручную создать новую встречу; автоматическое копирование/перенос платежей и отдельное аннулирование ошибочной встречи ещё не реализованы. Не закрывать ошибочную встречу фиктивными платежами.

Следующие задачи: скидки и чаевые с документированными правилами округления, несколько плательщиков, компании, OCR, импорт/экспорт всей базы. Эти возможности не входят в работающий прототип.


## Профиль и друзья

В локальном профиле хранятся имя организатора и реквизиты. Организатор автоматически добавляется в новую встречу и считается плательщиком всего чека. В список друзей человека можно добавить только по имени, а телефон, день рождения и описание заполнить в отдельной карточке. Карточка показывает историю встреч и графики расходов. Общие суммы, среднее и максимум учитывают только зафиксированные и закрытые встречи; черновики видны отдельно.
