# Работа с ИИ

## Начало в VS Code

Откройте D:\Projects\My\PoDolyam в обычном VS Code под Windows 11. Начните диалог Codex с задачей и ограничениями.
Попросите сначала прочитать AGENTS.md, проверить Git-статус и актуальный ROADMAP.
Среда агента может отличаться от терминала VS Code: проверяйте, что Git, Go и npm.cmd запускаются нативно в Windows.
Если sandbox не запускается, это ошибка среды; не отключайте защиту и не меняйте глобальные разрешения ради инструкции проекта.

## Инструкции

Codex читает AGENTS.md по иерархии каталогов; AGENTS.override.md имеет приоритет над AGENTS.md в том же каталоге.
Подробные файлы .ai/rules/ не загружаются автоматически: корневой AGENTS.md требует явно читать соответствующие правила.
CLAUDE.md служит короткой ссылкой на те же правила.
Локальные замечания можно хранить в игнорируемом .ai/local/context.md и явно указывать его в запросе. Автоматическую загрузку этого файла не предполагаем.

Сверено по [официальной инструкции OpenAI об AGENTS.md](https://developers.openai.com/codex/guides/agents-md), 15.09.2026.
Глобальные настройки пользователя и конфигурацию плагинов проект не изменяет.

## Окружение и проверки

В PowerShell: `make help`, затем `make test` и `make build`. Требования — docs/DEVELOPMENT.md.
Перед завершением агент сообщает, какие команды действительно выполнены и какие проверки заблокированы.
Документы, OpenAPI и TestCases.md обновляются вместе с изменением поведения.
Не сохраняйте пароли, ключи и токены в инструкциях.

## Примеры запросов

- Функция: «Реализуй следующий этап денежного ядра из ROADMAP. Сначала прочитай правила money/tests, добавь реальный пример и fuzz».
- Исправление: «При распределении 100 копеек на троих теряется копейка. Воспроизведи тестом, исправь, проверь инварианты».
- Review: «Проверь изменения без редактирования: права владельца, CSRF, переполнение, транзакции и тестовые пробелы. Укажи файл и строку».

Коммит, push и production-деплой — только по отдельной просьбе.
