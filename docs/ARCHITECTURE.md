# Архитектура

## Текущая цель: Windows 11

По решению пользователя проект перенесён в Windows: отдельное окно вместо серверного приложения. Основной путь сборки — make build. Wails 2.16.0 использует системный WebView2 для Vue 3; Go исполняет расчёты и операции хранения. SQLite modernc.org/sqlite 1.59.0 работает без отдельного сервера и C-компилятора при обычной сборке.

## Границы

- backend/internal/money — чистые расчёты int64, без UI и БД. Версия алгоритма largest-remainder-v1.
- backend/internal/local — SQLite, транзакции, версия черновика, сохранённые снимки и журнал платежей.
- backend/cmd/desktop — окно Wails, встраивание готового frontend через embed.FS, буфер обмена, персональный PDF.
- `frontend/src/desktop.ts` — типизированная граница вызовов Go. Маршрутизация окна всегда использует hash history.
- `backend/internal/meetings` содержит модели встречи и валидацию черновика без привязки к хранению.

Request(method, path, body) — переходный JSON-адаптер существующих экранов, а не сетевой REST-сервер. Приложение не слушает HTTP-порт. Один локальный профиль принадлежит текущему пользователю Windows; отдельной регистрации и пароля приложения нет.

## Хранение и инварианты

SQLite хранит документ встречи вместе с расчётом и платежами. PRAGMA user_version=3 задаёт версию схемы; неизвестная будущая версия отклоняется. Каждое изменение — одна транзакция. Один SQL connection последовательно обрабатывает записи; это простое решение для одного пользователя, без фоновых workers.

Версия черновика предотвращает перезапись устаревших изменений. Финализация проверяет полное распределение и ресторанную сумму и сохраняет снимок. SQL-триггер дополнительно защищает зафиксированные входы и расчёт. Остатки вычисляются по неизменяемому долгу и неотменённым платежам. Отмена сохраняет исходную запись, время и причину. Закрытие разрешено при нулевых остатках.

Порядок участников для округления не меняется. Удаление участника требует предварительно разрешить назначения. «На всех» сохраняет выбранный состав на момент действия.


Справочник friends хранит стабильный ID, имя, телефон и необязательную дату рождения. При добавлении друга во встречу копируются ID и текущее имя: будущая статистика сможет группировать встречи по ID, а старый снимок не зависит от последующего переименования или удаления записи справочника. Профиль me автоматически становится плательщиком новых встреч.

## Безопасность и обмен

Данные не зашифрованы приложением; защита зависит от учётной записи и прав Windows. Сетевой вход и серверные сессии к локальному профилю не применяются. Не загружать в привилегированный WebView внешние страницы и не исполнять пользовательский HTML. PDF формируется из зафиксированного расчёта Go, использует системный Unicode-шрифт Windows и включает только доли выбранного участника и сохранённые реквизиты плательщика.

Персональный PDF — статический файл на момент экспорта, без токена и возможности отзыва уже отправленной копии. Общедоступная ссылка потребовала бы сервера и сейчас отсутствует. Автоматического импорта прежних серверных данных нет.
