# Выпуск и сохранность данных Windows

Основной артефакт — build/PoDolyam.exe, создаваемый make build. Vue встроен в exe; отдельные Node, Go, PostgreSQL и Docker конечному пользователю не нужны. Нужен Microsoft Edge WebView2 Runtime. Установщик и цифровая подпись пока не подготовлены; публикация не выполнялась.

## Обновление

1. Закрыть PoDolyam.
2. Скопировать %LOCALAPPDATA%\PoDolyam\podolyam.db в отдельное защищённое место с датой в имени.
3. Сохранить предыдущий exe и заменить приложение новым.
4. Запустить, проверить встречи и остатки.

Не удалять каталог данных при обновлении exe. WebView2 — кэш интерфейса, он не заменяет базу. При PODOLYAM_DATA_DIR база находится в указанном каталоге.

## Проверка восстановления

Закройте приложение. Скопируйте резервную базу в отдельный каталог, задайте PODOLYAM_DATA_DIR этим абсолютным путём в текущем терминале и запустите exe. Проверьте известную встречу, снимок и платежи. После закрытия удалите переменную из текущего окружения. Не перезаписывайте единственную рабочую базу для теста.

Процедура пока ручная; автоматический backup/restore не реализован. Копировать открытую базу обычным файловым копированием не следует.

## Откат

При совместимой схеме можно вернуть предыдущий exe. Неизвестная новая версия SQLite-схемы отклоняется. Откат exe не откатывает данные: при несовместимой миграции понадобится совместимая резервная база, с потерей изменений после её создания. Миграций после версии 1 пока нет.

## Прежний серверный вариант

Сохранённые deploy/, Compose и .env.example относятся к HTTP/PostgreSQL-прототипу. VPS, GHCR, HTTPS и SSH-деплой для Windows-приложения не нужны и в рамках этого перехода не настраивались.
