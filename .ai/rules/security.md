# Безопасность

- Секреты вне Git; не хранить токены в инструкциях, frontend или localStorage.
- Desktop работает от текущего пользователя Windows. Не обещать шифрование SQLite или отдельную авторизацию: их нет.
- Не загружать внешние страницы в WebView с привилегированным мостом Go. Не использовать v-html для названий.
- Экспорт — только личный расчёт, экранированный HTML без скриптов; статическую отправленную копию нельзя отозвать.
- Не добавлять сетевой сервер или открытые отладочные порты в production-сборку.
