# Деньги

- Все суммы int64 в копейках; API — целые числа. Никаких float для стоимости.
- Лимиты и проверки переполнения см. docs/CALCULATIONS.md.
- Авторитетная стоимость строки = целое положительное количество × цена единицы.
- Положительные веса, уникальные участники; в режиме единиц сумма количеств равна заказанному.
- Метод наибольших остатков по каждой строке. Равенство разрешает неизменяемый порядок участника.
- Сумма долей точно равна стоимости строки. Нераспределённые строки видны и препятствуют финализации.
- Доля плательщика не долг. Возвраты не превышают обязательство.
- Финализация только после полного назначения и независимой сверки. Снимок неизменяем.
- «На всех» сохраняет текущий состав, добавление участника не меняет назначения.
