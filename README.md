# 🍕 PoDolyam

### Делим ресторанный счёт без Excel, споров и потерянных копеек

**Windows edition · v0.2.0**

Организатор создаёт встречу, добавляет друзей и блюда, распределяет позиции — PoDolyam точно считает доли, фиксирует результат и помогает собрать переводы.

</div>

---

## ✨ Что умеет приложение

### 👥 Встречи и друзья

- организатор автоматически становится участником и плательщиком новой встречи;
- справочник друзей хранит имя, телефон и день рождения;
- сохранённого друга можно добавить во встречу одним нажатием;
- постоянный ID друга создаёт основу для будущей общей статистики;
- встречу можно удалить только через отдельное предупреждающее окно.

### 🧾 Чек и распределение

- личные блюда одному человеку;
- общие позиции поровну между выбранными участниками;
- распределение «На всех» с фиксацией текущего состава;
- деление по количеству единиц или целым весам долей;
- независимая сверка суммы позиций с итогом ресторанного чека;
- заметный список нераспределённых позиций.

### 💰 Точные расчёты

- все суммы хранятся в целых копейках — `int64`, без `float`;
- остаток от деления распределяется методом наибольших дробных остатков;
- повторный расчёт с теми же данными всегда даёт тот же результат;
- сумма долей каждой позиции точно совпадает с её стоимостью;
- собственная доля плательщика не превращается в долг самому себе.

### 📊 Итог и возвраты

- Excel-подобная матрица: строки — участники, столбцы — блюда;
- подробный лог расчёта каждой позиции;
- фиксация неизменяемого снимка итогов;
- учёт частичных и полных переводов;
- отмена ошибочной записи с сохранением причины;
- персональный PDF-чек с блюдами, формулой расчёта, остатком и реквизитами;
- копирование готового сообщения для отправки участнику.

## 🚀 Быстрый запуск

### Запуск собранного приложения

После `make build` откройте файл:

```text
build\PoDolyam.exe
```

Для интерфейса нужен **Microsoft Edge WebView2 Runtime**, который обычно уже установлен в Windows 11.

### Сборка из исходников

Потребуются:

- Windows 11;
- Go `1.27.1`;
- Node.js `24.19+`, но ниже `25`;
- GNU Make `4+`;
- Microsoft Edge WebView2 Runtime.

```powershell
git clone https://github.com/gjhonic/PoDolyam.git
cd PoDolyam

make help
make test
make build

.\build\PoDolyam.exe
```

`make build` устанавливает зависимости по lock-файлу, собирает Vue и встраивает готовый интерфейс внутрь Windows `.exe`.

## 🛠️ Команды

| Команда | Назначение |
|---|---|
| `make help` | 💡 Показать красивую подсказку |
| `make test` | 🧪 Проверить Go, Vue, денежное ядро и fuzz-сценарии |
| `make build` | 📦 Собрать `build\PoDolyam.exe` |

Makefile рассчитан на **нативный Windows-терминал**. WSL, Docker и PostgreSQL для desktop-приложения не нужны.

## ⚙️ Настройка версии

Версия задаётся в корневом `.env`:

```env
APP_VERSION=0.2.0
```

Начать можно с примера:

```powershell
Copy-Item .env.example .env
```

Если `.env` отсутствует, локальная сборка использует значение из `.env.example`. Версия отображается в шапке рядом с надписью **Windows edition**.

## 🗃️ Где хранятся данные

Локальная SQLite-база находится здесь:

```text
%LOCALAPPDATA%\PoDolyam\podolyam.db
```

В ней хранятся:

- профиль организатора и реквизиты для перевода;
- список друзей;
- встречи, участники и позиции чеков;
- зафиксированные расчёты;
- история полученных и отменённых переводов.

> ⚠️ Копирование одного `.exe` не переносит данные. Удаление встречи через интерфейс необратимо. Перед переносом компьютера сохраните резервную копию базы.

## 🧱 Технологии

| Область | Технологии |
|---|---|
| Desktop | Wails v2, системный WebView2 |
| Backend desktop | Go, Wails bridge, чистое денежное ядро |
| Локальное хранение | SQLite через `modernc.org/sqlite` |
| Frontend | Vue 3, TypeScript, Vite, Vue Router |
| PDF | `gopdf` + системный Unicode-шрифт Windows |
| Проверки | Go test, fuzz-тесты, Vitest, ESLint, vue-tsc |

## 📁 Структура проекта

```text
backend/
  cmd/desktop/       # Windows-приложение Wails
  internal/local/    # SQLite и локальные операции
  internal/money/    # расчёты в копейках
  internal/receipt/  # персональные PDF
frontend/
  src/views/         # встречи, друзья, профиль и расчёты
  src/               # router, API-мост, типы и стили
docs/                # продукт, архитектура и правила расчёта
scripts/windows.mjs  # test/build для Windows
installer/           # исходник установщика Inno Setup
build/               # локальный exe, не хранится в Git
```

## 🧪 Проверки качества

`make test` запускает:

- `gofmt` check;
- `go vet`;
- все Go unit-тесты;
- ограниченные fuzz-прогоны денежного ядра;
- TypeScript typecheck;
- ESLint;
- frontend-тесты Vitest.

Отдельными тестами проверяются реальные временные SQLite-базы, миграции, неизменяемость снимка, платежи, удаление встреч, Wails bridge и создание Unicode PDF.
