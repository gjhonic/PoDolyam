# Git

- Ветки: feature/<краткая-тема>, fix/<краткая-тема>; при реальной задаче feature/PD-<номер>-<тема>.
- Реальные задачи, PR и коммиты ссылаются на PD-<номер>. Номер не выдумывать; до появления задачи использовать описание без фиктивного ID.
- Коммит, push, создание remote и production-деплой требуют отдельной просьбы пользователя.
- Не стирай чужие изменения, не делай force push.
- PR: проблема, итоговое поведение, проверки и ограничения. Заголовки и описание на русском.
- Основной путь — PR в main с обязательным CI. Варианты review см. docs/GITHUB_SETUP.md.
