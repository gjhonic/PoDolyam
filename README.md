# PoDolyam для Windows

Приложение для разделения ресторанного счёта: участники, назначения блюд, точные копейки, фиксация расчёта и ручной учёт возвратов. Отдельное окно Windows 11, Go + Wails + Vue, локальная SQLite. Интернет для повседневной работы не нужен.

## Запуск

Готовая локальная сборка: `build\PoDolyam.exe`. Откройте двойным щелчком. Нужен Microsoft Edge WebView2 Runtime; WSL, Docker и PostgreSQL для Windows-приложения не требуются.

Из PowerShell в корне проекта (Go 1.27.1, Node 24.19+ ветки 24 и GNU Make 4+):

```powershell
make help
make test
make build
.\build\PoDolyam.exe
```

Данные: `%LOCALAPPDATA%\PoDolyam\podolyam.db`. Копирование exe не переносит встречи. Резервное копирование — [DEPLOY](docs/DEPLOY.md).

## Возможности и ограничения

- Личные и общие блюда, равные доли, количество единиц, целые веса, действие «На всех».
- Сверка с ресторанным чеком, неизменяемый снимок, частичные возвраты и отмена ошибочной записи с причиной.
- Копирование сообщения и экспорт персонального PDF через окно сохранения. Экспорт — статическая копия, которую пользователь отправляет сам.
- Организатор из раздела «Я» автоматически становится участником и плательщиком новой встречи. Справочник друзей хранит имя, телефон и день рождения; постоянный ID друга переносится во встречу для будущей статистики.
- Один локальный профиль Windows. Нет облачной синхронизации, публичных ссылок, установщика, цифровой подписи и импорта прежней PostgreSQL.
- Скидки, чаевые и несколько плательщиков пока отложены.
