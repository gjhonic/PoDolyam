# План PoDolyam

## Переход на Windows — 17.09.2026

Текущая цель: отдельное окно Windows 11, локальные данные, прежняя логика расчётов. Рабочий репозиторий D:\Projects\My\PoDolyam. WSL-копия не обновляется.

1. **Реализовано:** Wails/Vue, SQLite, команды install/test/build/run, сборка build/PoDolyam.exe.
2. **Реализовано:** встречи, участники, позиции и назначения, сверка, снимок, частичные платежи, отмена и закрытие; существующее денежное ядро сохранено.
3. **Реализовано:** StreetArt-интерфейс встречи: группа и описание, участники, карточки чека, итоговая таблица, лог подсчёта и статистика; зафиксированный чек доступен для чтения.
4. **Реализовано, нативные действия требуют ручной проверки:** копирование через Wails и экспорт персонального PDF через диалог сохранения.
5. **Следующий этап:** воспроизводимая автоматизация настоящего окна WebView2, проверка всего пользовательского пути, улучшение ошибок старта, установщик и подпись по отдельной задаче.
6. **Позже:** импорт прежних данных, резервное копирование из интерфейса, скидки/чаевые, несколько плательщиков, OCR. Не показывать как готовые функции.

## Выполненные проверки Windows

- make build: Vite production + Go Windows amd64 exe — успешно.
- make test: go vet, go test ./..., три fuzz-цели по 5 секунд, typecheck, ESLint, 18 frontend-тестов — успешно.
- SQLite: полный жизненный цикл, защита снимка, аудит отмены, переплата, сохранение после открытия базы заново, конкурентные платежи.
- Денежный пример: 882000 копеек; суммы 124168 / 152168 / 119166 / 148166 / 172166 / 166166; возврат 757832.
- Тестовый exe запущен с отдельной базой, процесс создал SQLite и WebView2. Автоматическое чтение окна через CDP недоступно: используемый загрузчик Wails сбрасывает переменные отладки WebView2. Полный нативный E2E и диалог экспорта пока не подтверждены.
- На Windows race detector не запускался. Отдельный Linux job проверяет money/local с race; GitHub workflow подготовлен, удалённый запуск не выполнен.




## Улучшение итогов и PDF — 17.09.2026

- Реализованы вкладки встречи без изменения hash-маршрута, Excel-подобная матрица «участники × позиции» и исправленная компоновка итогов.
- В главном меню добавлен раздел «Я»: телефон и банк хранятся локально в SQLite; схема автоматически мигрирует с версии 1 на 2.
- После фиксации напротив участника доступен персональный PDF: состав доли, правила распределения, суммы, переводы и реквизиты.
- Unit-проверка PDF создаёт Unicode-документ. Нативный диалог сохранения и внешний вид в окне требуют ручной проверки собранного exe.


## Организатор и друзья — 17.09.2026

- Организатор из профиля автоматически становится участником и плательщиком новой встречи; ручной выбор плательщика убран.
- Реализован локальный справочник друзей: имя, телефон, необязательный день рождения, изменение и удаление.
- Друг добавляется во встречу с постоянным ID. Агрегированная статистика по человеку остаётся следующим продуктовым этапом.
- SQLite автоматически мигрирует с версий 1 и 2 на версию 3 без изменения существующих встреч.
- Старый черновик без плательщика при открытии связывается с организатором из профиля; зафиксированные встречи не меняются.

## Удаление встреч и версия — 17.09.2026

- В главном меню реализовано необратимое удаление встречи через предупреждающее модальное окно; SQLite и Wails bridge покрыты тестами.
- APP_VERSION задаётся через env сборки и отображается рядом с Windows edition в шапке приложения.

## Очистка desktop-кода — 17.09.2026

- Удалены неиспользуемые HTTP/PostgreSQL-прототип, OpenAPI, Compose и web-E2E.
- Vue работает только через Wails bridge: убраны web-авторизация, публичные ссылки и условные desktop/web-ветки.
- Модели встречи отделены от SQLite; из зависимостей удалены pgx, Playwright и Redocly.
