# PoDolyam

Windows-приложение разделения ресторанного счёта. Общение, пользовательские тексты и документация — на русском.

## Структура и команды

- `backend/` — Go, Wails, SQLite; денежное ядро отдельно от хранения и окна.
- `frontend/` — Vue 3, TypeScript, Vite, Vue Router.
- `docs/` — продукт, решения, контракт и состояние этапов.
- `deploy/`, `.github/workflows/` — окружение и проверки.
- `make help`, `make test`, `make build` — публичные команды Windows.
- Основная разработка — Windows 11, PowerShell, нативные Go, Node и GNU Make. WSL не требуется. Compose относится к сохранённому web-прототипу.

## Перед работой

Прочитай `docs/ROADMAP.md` и `docs/ARCHITECTURE.md`, проверь Git-статус.
Общие правила явно прочитай по области задачи:

| Область | Файлы |
|---|---|
| Go и БД | `.ai/rules/backend.md` |
| Интерфейс | `.ai/rules/frontend.md` |
| Расчёты | `.ai/rules/money.md`, `docs/CALCULATIONS.md` |
| API и доступ | `.ai/rules/api.md`, `.ai/rules/security.md` |
| Проверки | `.ai/rules/tests.md` |
| Git и PR | `.ai/rules/git.md` |
| Окружение, CI/CD | `.ai/rules/deployment.md` |

Каталог `.ai/rules/` не считается автоматически загруженным.
Если пользователь указал локальный файл из `.ai/local/`, прочитай его явно.

## Порядок изменений

Сохраняй существующие изменения. Реализуй небольшие законченные этапы и запускай подходящие проверки.
Обновляй документацию вместе с кодом; планируемое не называй работающим.
Кратко объясняй существенные решения Go. Не вводи конкурентность и инфраструктуру без задачи.
Коммиты, push, удалённый репозиторий и production-деплой — только по отдельной просьбе.
Не меняй глобальные настройки ИИ. Не придумывай номера задач.
