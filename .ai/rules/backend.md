# Go и БД

- Пакеты группируй по ответственности: чистый расчёт отдельно от HTTP, хранения и внешних систем.
- Используй стандартную библиотеку, пока конкретная задача не требует зависимости.
- Небольшой интерфейс объявляет потребитель, если ему нужна подмена. Не создавай обязательные Interfaces/Exceptions и DI-контейнер.
- Ошибки возвращай через error, добавляй контекст через fmt.Errorf с %w; проверяй errors.Is/As. Не раскрывай внутренние ошибки клиенту.
- context.Context передавай первым аргументом в операции ввода-вывода. Не храни request context в структурах и не подменяй его Background.
- Зависимости собирай явно в `cmd/desktop`. Настройки читай на старте.
- Транзакция охватывает бизнес-действие целиком. Rollback через defer; проверка прав и конкурентных изменений внутри той же транзакции.
- SQL параметризован. Desktop использует `database/sql` и SQLite, `user_version` для схемы.
- Горутины добавляй только с понятным владельцем, завершением и обработкой ошибок.
