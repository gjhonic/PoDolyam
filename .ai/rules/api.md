# Граница интерфейса

- Desktop: вызовы Wails через frontend/src/desktop.ts и cmd/desktop; Request — переходный адаптер без сетевого порта.
- Суммы — целые копейки. Проверяй типы, диапазоны, неизвестные поля и размер JSON. Не превращай отсутствие значения в ноль.
- Права: один локальный профиль Windows. Проверяй принадлежность вложенных участников и платежей встрече.
- Экспорт участника включает только его доли; пользовательский текст передаётся в PDF как данные.
