# Проверки

- Перед завершением Windows-этапа: `make test` и `make build`.
- Денежное ядро: таблицы ошибок/границ, реальный пример, ограниченные fuzz-прогоны. Поддерживай TestCases.md рядом с тестами.
- SQLite: настоящие временные файлы, сохранность после открытия заново, неизменяемость снимка, транзакции, переплата и аудит отмены.
- Frontend: typecheck, lint, тесты значимого поведения. Нативный E2E должен запускать реальный exe; web E2E не заменяет проверку моста Wails.
- Системные диалоги и буфер обмена проверяй отдельно. Незавершённые проверки явно отмечай в ROADMAP.
- Серверный integration-набор требует настоящей PostgreSQL и build tag integration; не считать его запущенным обычным go test.
- Race detector для money/local запускается в Linux CI. Обычные Windows Go-тесты не являются race-проверкой.
