# Frontend

- Vue SFC, Composition API, script setup и строгий TypeScript.
- Компоненты группируй по сценарию. Pinia только при необходимом общем состоянии.
- Расчёт денег принадлежит backend. Клиент форматирует копейки и валидирует ввод, но не определяет обязательства.
- Для запросов предусмотри загрузку, ошибку, повтор; для списков — пустое состояние.
- При сохранении блокируй повторный submit, возвращай состояние при ошибке. Ошибки полей рядом с доступными label.
- Mobile-first: карточки позиций, выбор участников, элементы не менее 44px, видимый focus.
- Не показывай отложенные функции как работающие. Черновик и снимок должны визуально различаться.
